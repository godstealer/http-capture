# HTTP Capture 桌面版更新说明（2026-10-28）

本版包含 0.1.67 之后的桌面改动。版本号由同一源码提交的 GitHub Check 编号决定；跨平台检查、打包和签名完成后才作为正式版发布。

## 更新内容

- **响应正文查找**：文本响应可打开搜索框，并使用 CodeMirror 的查找快捷键；JSON 响应增加折叠根节点和展开全部操作，多行对象及数组的各级节点也可从行号旁折叠。
- **局域网协同抓包入口**：桌面端新增二维码配对入口和独立的加密接收端，使用一次性短期令牌与设备身份校验。连接后可记录远端连接和首个 HTTP 请求的可见元数据。
- **Android 协同抓包开发链路**：Android 端增加扫码配对及通过 VPN 转发 TCP/UDP 的代码。该部分仍需模拟器和真机端到端验收，本次不发布正式 Android 安装包，也不将其列为已完成能力。

## 使用与验证边界

局域网协同抓包默认不安装抓包 CA，HTTPS 正文不可见；手机 VPN、DNS、UDP/QUIC、切网、长连接和断线清理仍需目标设备验收。移动版不进入桌面自动更新频道。PC 二维码及接收端不等同于已完成的移动端交付；范围见[局域网协同抓包](mobile-lan-capture.md)和[路线图](roadmap.md)。

本地前端 TypeScript 和生产构建通过；上一批源码的 Windows、Linux、macOS 与前端同源 Check 全部通过。本次最终提交还须通过自己的四平台 Check、正式打包、签名与公开附件核验。安装及业务行为仍需实际设备验收。
