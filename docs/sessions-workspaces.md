# 会话、集合与环境

更新：2026-10-11。以下功能已接入开发版；旧 Release 安装包不自动获得这些功能。

## 会话数据

- 启动时读取全部历史及正文，不分页、不限制总条数。之后同步变化的记录和删除通知；表格只渲染可见行，搜索、全选、排序、导出仍覆盖完整列表。
- “保存当前列表”受当前过滤条件影响；“保存选中”只保存选择项。JSON 保存工具模型，HAR 用于与其他工具交换。两者都不等于数据库备份。
- “备份数据库”在数据目录的 `backups` 下生成唯一命名的 SQLite 文件，使用 `VACUUM INTO` 获取一致快照，界面显示路径。包含抓包、重放、SQLite 设置、工作区和集合；不包含外部代理配置文件、系统凭据库密码、CA 私钥和浏览器本地偏好。
- “清空全部记录”会清除抓包及重放历史，保留设置与集合。界面要求确认，建议先备份。删除标记防止仍在结束中的旧请求重新出现；新请求仍可写入。
- “回收数据库空间”执行 VACUUM，不清除历史，执行时数据库写入需等待。磁盘需有足够临时空间。应用不会自动裁剪历史。

### 导入

HAR / 会话 JSON 在 Worker 中解析，按批次写入暂存表，全部成功后一次提交。失败会尝试取消暂存，未提交内容不会出现在记录列表；遗留超过 24 小时的暂存任务在下次开始导入时清理。

不再限制文件总大小或总记录数。当前仍整体解析文件，内存消耗与文件大小有关，尚非流式 JSON 解析。每批最多 1000 条或约 32 MiB，单条记录的序列化上限为 60 MiB；HTTP 批次接口上限 64 MiB。导入会生成新 ID、清除脚本和代理关联，不执行导入内容中的脚本。

HAR 保留数组字段顺序和重复项，但不能证明原始线上顺序。响应正文按解码内容导出；二进制以 Base64 保存。无法解压时使用工具扩展字段保存原始字节并记录错误。二进制请求正文同样使用扩展字段，其他 HAR 工具未必识别。只有总耗时已采集，HAR 不虚构 DNS/TLS 等分段耗时。TLS 元信息、WebSocket 帧和脚本等工具特有信息请用会话 JSON 保存。

### 备份恢复

当前没有 GUI 恢复向导。恢复 SQLite 快照必须先退出所有使用该数据目录的桌面端和开发服务。将现有数据库及其 `-wal`、`-shm` 文件作为一组保留到另一个备份目录，再把快照复制为原数据目录下的 `sessions.db`。不要让旧 WAL 与恢复文件混用，也不要在运行中替换数据库。重新启动后加载快照内容。

跨机器迁移时，代理密码需要重新输入，CA 信任需要在目标机器单独设置。不要将抓包数据库、导出文件或 CA 私钥上传到公开仓库。

## 请求集合与环境

本地开发版的请求标签支持右键菜单：关闭当前、其他、左侧、右侧或全部请求标签。固定的“调试”页右键可关闭全部请求标签。关闭会移除对应工作区草稿并取消对应发送任务和 WebSocket；需要以后复用的请求请先保存到集合。

“集合与环境”标签独立于请求编辑标签。创建集合、填写名称后可收藏当前请求；关闭编辑标签不会删除收藏。收藏是草稿快照，之后编辑不会自动改写收藏。集合目前为平级分组，不支持嵌套目录。

创建命名环境，在带高亮的 JSON 编辑器中填写字符串键值对象，先“应用变量”，再“保存集合与环境”。发送页选择环境后，`{{name}}` 可用于 URL、请求头和 UTF-8 正文。环境变量作为基础，请求脚本变量覆盖同名值；不递归展开、不自动 URL 编码。缺失变量阻止发送，二进制正文保持原样。选择的环境不会被请求脚本写回。

```json
{
  "host": "httpbin.org",
  "token": "replace-me"
}
```

URL 示例：`https://{{host}}/get`。请求头示例：`Authorization: Bearer {{token}}`。

“保存当前脚本模板”复制当前请求的脚本配置；请求页的模板选择器将其复制到草稿。应用后修改草稿不会修改模板。

集合/环境导入只替换本地编辑内容，点击保存才写入数据库。保存使用版本号检查，多个窗口冲突时拒绝覆盖，先导出本地编辑再重新加载；没有自动合并。集合整体限制为 8 MiB，适合请求定义，不用于保存大量响应。导出文件可能含变量或认证信息。

### 从其他工具导入集合

打开“集合与环境”→“从其他工具导入”，选择来源、导出文件或粘贴内容，先看集合与请求数量及转换提示，再点“添加到集合”。这会**追加**到当前编辑内容，不覆盖原集合；最后还需点击“保存集合与环境”。原文件在本机解析，不上传。与之不同，顶部“导入本应用备份”会替换当前编辑内容，适用于本应用导出的 `request-library.json`。

支持的来源为 Postman Collection v2.1 JSON、Hoppscotch Collection JSON、OpenAPI 3 JSON、Insomnia Export v4 JSON、HAR JSON 和单条 cURL 命令。ApiFox、ApiPost、Paw 等工具可先导出 Postman v2.1 或 OpenAPI 3 JSON 再导入。Insomnia v5 YAML 和 OpenAPI YAML 暂不支持。集合目前只有平级分组；来源工具中的嵌套目录会展平为请求名称的一部分。

导入会保留能够映射的 URL、方法、请求头、文本或可编码正文；预览中的转换提示会列出不能完整映射的认证、动态脚本、本地文件或其他字段。请先核对提示和导入后的请求，再发送。HAR 导入的是请求快照，不导入响应或浏览器运行状态；浏览器导出的 HAR 可能已去除敏感请求头。文件与最终集合均受 8 MiB 限制，请按项目拆分较大的导出文件。导出文件及集合可能包含 Cookie、授权头和变量，请按凭据管理。

## 表单、规则和代理测试

- 请求体支持“无正文”、UTF-8 文本/JSON、Base64、URL 编码表单、Multipart 文件字段和原始文件。0 字节正文默认显示“无正文”，URL 查询参数不作为请求体；主动选择“无正文”会清空已有正文。
- 表单初始提供一行可填写字段，未编辑的占位行不发送。点击“添加字段”后会滚动到新增行，并将光标放在字段名中。填写后点击“应用到请求体”才更新实际发送内容；未应用的修改会明确标记，切换正文类型会暂存这些字段。支持载入现有表单及 Multipart 文件；仅查看不会重编码捕获内容，应用时会生成对应 Content-Type，Multipart 会重建边界。正文超过 8 MiB 时默认保留为文件，不自动解码。
- 规则支持单条启停、分组标记、排除规则和 JSON 导入导出。行内条件为 AND，普通行之间为 OR，任意匹配的排除行优先放行。分组暂为标签，不改变逻辑。导入后需点击应用。
- 断点命中计数按每个匹配普通规则的实际暂停次数累计，请求和响应可分别计数；修改配置或重启后归零，不代表全部匹配流量次数。
- 上游代理“测试隧道”连接 `example.com:443`，测试 HTTP CONNECT 或 SOCKS5 握手和认证。不会切换当前代理；成功不表示 TLS、HTTP 内容或 SOCKS5 UDP 已验证。
- 桌面 cURL 导入/复制使用 Tauri 原生剪贴板；浏览器使用 Web Clipboard，权限不可用时仍可手动粘贴。
- 本地开发版的 cURL 导入支持重复的内联 `--data-urlencode 'name=value'`、`=content` 和普通内容；字段值按 UTF-8 编码，空格转换为 `+`，字段名保留已有编码。搭配 `-G/--get` 时追加到 URL 查询，不生成请求正文。`@file`、`name@file` 和标准输入读取仍需用户改为内联字段，导入器不会读取本地文件。格式含义见 [cURL 参数说明](https://curl.se/docs/manpage.html#--data-urlencode)。

## 响应文本搜索（本地开发版）

点击格式化或原文中的响应文本后按 `Ctrl+F`（macOS 为 `⌘F`），可在当前文本内搜索，并用 Enter 跳到下一个匹配项。只读正文可获得键盘焦点，搜索不会修改响应。抓包详情的请求和响应各自搜索所在面板；分页原始文本、Hex 和 Base64 仅搜索当前页，换页不会为搜索而加载完整正文。

## 大正文二进制存储（第一阶段）

超过约 64 KiB 的请求/响应正文（含修改前副本）写入同一 SQLite 数据库的 `flow_bodies` BLOB 表，JSON 只保留内部引用。公开接口、会话 JSON 和 HAR 仍返回完整 Base64 正文，不分页、不截断记录。小正文和旧内嵌记录保持兼容；旧记录不在启动时批量重写，后续更新时采用新格式。

正文与记录的更新、删除、导入使用同一事务，备份仍为完整单文件 SQLite；损坏或缺失的正文引用明确报错，不伪装成空正文。回收数据库空间仍使用 VACUUM。旧版本软件不了解新的内部引用，降级前应导出会话 JSON 或保留升级前数据库备份。

本阶段降低 Base64 的磁盘存储开销，不代表已实现网络流式落盘。网络单向 8 MiB 限制、读取全部正文的内存开销及 WS 帧正文内嵌格式仍保留。数据库复制恢复必须停机；不可只复制 flows 表而遗漏 flow_bodies。
