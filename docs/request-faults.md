# 请求故障模拟

故障模拟用于检查程序遇到请求延迟、本地 429 时的超时、取消和重试处理。入口是 **阻止请求 → 故障模拟**，需要先连接抓包内核。本文说明当前实现；安装包实际范围与发布状态见[更新说明](release-2026-10-20.md)。

## 添加一条延迟规则

1. 打开 **故障模拟**，点击 **添加规则**。
2. 选择匹配方式，填写匹配内容。测试单个域名时可选 **域名精确匹配**，例如 `example.com`；不要带协议、端口、路径或通配符。也可选 **URL 包含** 或 **URL 正则表达式**。
3. 需要限定方法时填 `GET`、`POST` 等；留空表示任意方法。
4. 在 **请求延迟（ms，0 关闭）** 填 `1000`，表示发送 HTTP 请求前额外等待一秒。
5. 保持该条 **启用规则** 勾选，勾选页面的 **启用故障模拟**，按需选择作用范围，最后点击 **保存规则**。

输入、总开关与单条规则开关都先修改编辑内容，**保存后才生效**。看到“模拟规则已保存；计数已重置，下一条请求生效”后，再产生测试请求。需要暂时关闭时，取消总开关并再次保存。

默认范围是 **仅抓包流量**；选 **抓包和手动请求** 后也覆盖普通 HTTP 手动发送，包括经过同一管线的 MCP HTTP 发送。范围选择不会启动抓包监听，也不会自动发送请求。

## 设置固定窗口频率

在同一规则勾选 **限制请求频率**，填写 **窗口内允许次数** 和 **窗口时长（ms）**，保存后生效。例如允许 `5` 次、窗口 `1000` ms：从该规则第一条符合条件的请求开始计时，窗口内前五条允许继续，第六条本地返回 429；窗口到期后，下一条请求开始新窗口。

| 设置 | 可填写范围 |
| --- | --- |
| 请求延迟 | 0–30,000 ms；0 表示不额外延迟 |
| 窗口内允许次数 | 1–10,000 次 |
| 窗口时长 | 100–60,000 ms |
| 规则数量 | 最多 100 条 |

每条规则至少设置正延迟或频率限制，不能两项都关闭。两项同时开启时，先判断额度：超额立即返回本地 429，不再追加该规则的延迟；有额度才继续等待并发送。

**同一条规则共享一个窗口和计数**，不按域名、客户端或 IP 分桶。匹配多个 URL 时，它们合用额度。进入允许额度后，即使随后取消或上游失败，这次额度也已计入；超额请求不会继续消耗额度。成功保存配置或重启内核会清空窗口，运行中的计数不持久化。

这是按请求次数计数的固定窗口；正文传输字节、下载带宽和上传速度不参与计算。它不提供滑动窗口、匀速放行或响应正文限速。

## 匹配顺序与结果

按列表顺序使用**第一条启用且匹配的规则**，不会把多条规则的延迟相加。条件匹配请求脚本和请求断点编辑后的最终 URL、方法；URL 包含按实际字符匹配，域名精确匹配只比较主机名。

普通 HTTP 管线的顺序是：请求脚本/请求断点 → 阻止规则 → 故障模拟 → 上游发送。已被阻止的请求不再执行故障模拟。延迟由原请求的取消或停机过程取消，不会在后台补发。

频率超额的响应带有：

- HTTP 状态 `429`。
- `Retry-After`：当前规则窗口剩余等待时间，向上取整为秒。
- `X-HTTP-Capture-Simulated`：产生该响应的规则 ID。

这类记录可显示为本地阻止，表示模拟策略已处理，不能当作网站实际返回 429。普通 HTTP 请求没有向上游发送；但在 HTTPS 解密连接等场景，上游 TCP/TLS 连接可能已提前建立，因此不能据此推断完全没有连接网站。

## 编辑冲突与迁移

规则按读取时的配置版本保存。如果另一个窗口或内核已修改配置，旧版本会被拒绝，当前编辑内容保留。先复制需要保留的修改，点击 **取消修改 → 重新加载** 获取最新配置，再重新编辑保存；不要反复提交旧版本。

断线重连不会覆盖尚未保存的编辑；它也不会把旧草稿自动变成最新版本。**取消修改** 放弃当前本地编辑，**重新加载** 显式读取已保存内容。

[全局配置迁移](config-migration.md)中的 **模拟规则** 类别可以带入匹配、延迟和频率定义。导出、导入均关闭故障模拟总开关；导入成功后按迁移页提示重启，再检查范围并手动启用、保存。窗口起点和计数不随配置迁移。

## 支持范围与待实机验收

故障模拟覆盖普通 HTTP 请求，不处理 WebSocket、CONNECT 直通、交互式 gRPC 或正文传输速率。它不改变完整正文保存、转发和下载的字节语义，也不代表整个抓包链路已达到恒定内存或零拷贝。

实际安装包还需验证网页请求的延迟/取消/停止监听、固定窗口恢复与 `Retry-After`、多规则优先级、跨窗口冲突、模拟规则导入后禁用，以及窄窗口、缩放、主题和中英文显示。自动化与本机测试不能替代这些真实浏览器和设备场景。
