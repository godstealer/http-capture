# 2026-10-14 发布候选

## 已完成

- HAR 分批导入、进度遮罩、保存位置选择及 CA 导出入口；浏览器路径已实测。
- 界面缩放；请求正文与 Protobuf 定义代码编辑、格式化；SVG 静态预览；发送/接收/取消等状态。
- gRPC Native HTTP/2：proto 导入、服务反射、JSON 编解码、四种主动调用、metadata/trailers、折叠消息视图。HTTP/gRPC/WebSocket 分开选择。
- 本地 JavaScript 插件 API v1：HTTP 请求响应修改、URL 正则、来源范围、启停/排序/卸载、落盘和日志；错误回滚。
- Header Order 来源校验；H1 Reqable 固定样例与截图对照、原生 H2 独立 nghttp2 接收端验证。
- SQLite 增量 BLOB、正文暂存及 H1 分块 Base64，减少大正文中间副本。

## 未完成及重要边界

- 大文件仍非全链路低内存；未完成并发峰值内存压测。
- 桌面原生 HAR/导出对话框、缩放、关闭保存及跨平台安装需要实机验收。
- Reqable H2 MITM 对照、H3 原始字段顺序保真未完成。
- gRPC 仅 Native HTTP/2；实时抓包双向流、环境变量、多 schema、脚本/断点/插件暂未接入；切换请求工作区会取消活动调用。
- 插件不兼容 Burp Java，不支持扩展面板/菜单/扫描器/独立网络；沿用脚本大小限制，SSE 响应钩子受限制。示例默认禁用。
- TUN H3 实机验收仍暂停，其他协议和系统集成待办见 roadmap。

## 发布与验证

本地回归记录和细节见 roadmap、grpc、plugins、header-order-comparison 文档。GitHub Check 对本次提交通过后，自动构建 Windows x64、Linux x64（deb/AppImage/portable）、macOS Intel/Apple Silicon；四组构建成功后发布 build-提交哈希预览版本。构建排队或失败不代表安装包已发布。

本次提交前在 Windows 执行：`npm run test:frontend`、`npm run build`、`cargo test --locked -p capture-core --no-default-features`、服务端 3 项契约测试均通过。需要真实系统凭据或可选 helper 的 ignored 测试不计为通过；跨平台结果以本次 GitHub CI 为准。

## 后续增量：gRPC 工作区与退出清理

- gRPC 地址、metadata、服务反射和 JSON 消息支持环境变量；请求变量优先，流式会话固定启动时的变量快照。
- 切换工作区保留 gRPC 会话、方法和消息草稿；关闭标签或更换协议类型时取消调用。
- 方法和 JSON 草稿随工作区落盘，支持未完成 JSON，刷新后恢复；活动连接需重新发起。
- 桌面退出显式停止抓包监听、取消请求并清理 TUN；开发服务支持 Ctrl+C 和 Unix SIGTERM。
- 验证：真实本地双向流切换后继续发送、最终 grpc-status: 0、关闭标签取消、刷新恢复草稿；数据库恢复/旧格式兼容及端口立即重绑测试通过。桌面和服务编译通过。

以上仍不代表跨平台安装运行验收完成。关闭浏览器页面不等于退出独立开发服务。
