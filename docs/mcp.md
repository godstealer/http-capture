# MCP 接入

MCP 页面分为「AI 接入」和「外部服务」。前者让外部 AI 客户端操作正在运行的 HTTP Capture，后者在 HTTP Capture 中连接并手动调用外部 MCP 工具。两者默认均不连接；应用没有内置大模型，也不会自动把抓包记录发送给外部 MCP 服务。

## 让 AI 操作抓包工具

1. 在左侧打开 **MCP → AI 接入**，确认端口和权限。默认端口为 `1422`，与抓包代理和开发控制端口分别使用；端口被占用时启动失败并保留输入。
2. 点击 **启动 MCP**，再点击 **复制连接配置**。复制内容包含 `url` 及 `headers.Authorization`，例如以下结构（Token 为占位符）：

   ```json
   {
     "url": "http://127.0.0.1:1422/mcp",
     "headers": {"Authorization": "Bearer <应用生成的 Token>"}
   }
   ```

3. 在支持 **Streamable HTTP** 的 AI 客户端中填写这两项。不同客户端的外层配置结构不同，复制内容不是适用于所有客户端的完整配置文件。

服务只绑定 `127.0.0.1`，使用独立生成的 Bearer Token，不复用开发控制接口凭据。无效 Host、Origin 或 Token 在解析请求正文前拒绝。当前为本机固定凭据接入，不提供远程 OAuth 或旧式双端点 SSE。启用状态、端口和权限保存到数据库；应用正常重启后恢复，停止则保存为关闭。修改端口和权限前需先停止服务。Token 只在主动复制连接配置时返回，状态接口不返回它。

使用官方 Rust SDK `rmcp 3.5.1`，提供当前 `2026-07-28` 协议和 SDK 支持的旧版 `2025-03-26`、`2025-06-18`、`2025-11-25` 兼容处理。默认四个只读工具；勾选权限后增加工具：

| 工具 | 权限与用途 |
| --- | --- |
| `capture_status` | 默认；读取共用内核的监听状态与可用发送引擎 |
| `list_requests` | 默认；按 URL、方法、状态、来源过滤，游标分页，每页最多 200 条摘要 |
| `get_request` | 默认；读取请求/响应元数据，不附带完整正文、脚本、原始头或证书 |
| `read_body` | 默认；按请求 ID、方向及字节偏移读取正文，每次最多 64 KiB；返回 Base64 及有限文本预览 |
| `send_request` | 允许发送；通过当前上游、规则和公共执行管线发送普通 HTTP，请求结果保存到历史 |
| `cancel_request` | 允许发送；按执行 ID 取消活动请求 |
| `start_capture` / `stop_capture` | 允许控制抓包；操作界面使用的同一监听器，启动地址限本机 |

AI 发送首期支持 `auto`、`native`、`h2`，正文 Base64 最多 131072 字符。不能传入任意脚本、代理密码、自定义 TLS、WebSocket/gRPC 模式或额外配置字段。公共执行管线中已经启用的全局脚本和插件仍按原规则运行。MCP 请求体限制 256 KiB，结果限制 512 KiB，超限需减小页数或正文块大小。

默认隐藏敏感请求/响应头；可显式允许显示 Cookie、Authorization 等字段。URL 中的凭据、片段和敏感查询参数始终做脱敏；这是有限规则匹配，不是通用内容脱敏。**读取正文仍可能返回私人信息**，只把连接配置交给可信的 AI 客户端。捕获的正文是不可信数据，不应把其中的文字当作操作指令。

## 连接外部 MCP 服务

打开 **MCP → 外部服务 → 添加服务**，支持两种形式：

- **HTTP**：填写 Streamable HTTP 地址，按需要填写 Bearer Token。禁止自动跟随重定向，避免凭据被转发到其他地址。
- **stdio**：填写已安装的本地可执行程序及 JSON 字符串数组参数，例如程序 `node`，参数 `["C:/tools/my-mcp-server.mjs"]`。参数逐个传入，不经过 shell；不会自动安装依赖。

保存仅保存连接信息，点击 **连接** 后才访问服务或启动本地程序；再点击 **工具目录**，查看工具名称、说明和参数 Schema。填写 JSON 对象后点击 **手动调用工具** 查看结果。工具描述由外部服务提供，不代表应用为其安全性作保证。

HTTP Bearer Token **仅保留当前会话**，重启后必须补填；磁盘保留服务名称、地址/命令、参数及是否需要 Token。请勿将密码放入地址或命令参数。连接初始化及工具调用有超时；断开会取消本地在途操作并清理 stdio 子进程。远端已经开始的操作可能继续运行，失败或超时后不要直接假定未执行，也不会自动重试工具调用。

## 验证与后续

自动测试覆盖官方 SDK 新旧协议、认证/Origin/Host、权限、分页与正文范围、共用监听器、真实本地 HTTP 发送、HTTP 重定向、取消及 stdio 参数/清理。真实 AI 客户端接入、平台进程清理和应用安装升级仍见[验收清单](acceptance-2026-10-19.md)。MCP 远程授权、密钥库持久 Token、自动工具编排和通用配置迁移不属于本期。
