# HTTP Capture 桌面版更新说明（2026-11-11）

本版包含 0.1.71 之后的桌面改动。正式版本号取同一源码提交的 GitHub Check 编号；跨平台检查、打包和更新附件校验通过后才公开发布。

## 更新内容

- 导入 cURL 时识别 `--http1.1`、`--http2`、`--http2-prior-knowledge` 和 `--http3-only`，导出代码时保留可表达的 HTTP 协议选择。明文 HTTP 上的 h2c Upgrade 暂不支持，会给出明确错误。
- 请求头字段和请求 URL 支持 Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做。
- Ctrl+F 可直接搜索当前抓包列表或请求、响应正文；原有查找按钮继续可用。
- 重放页请求头表格铺满可用编辑区域，长列表在表格内滚动。

## 验证边界

本版仅发布桌面安装包。Android 局域网协同抓包仍待真机端到端验收，iOS 仍待签名设备验收；本版不发布正式移动安装包。macOS M1 安装启动及跨版本自动更新的真实设备验收仍保留在[开发清单](roadmap.md)。
