# HTTP Capture 本轮更新说明（2026-10-23）

本版汇总 0.1.34 之后已开发的功能与内存改造。最终版本号由同一源码提交的 GitHub Check 编号决定；只有检查及四平台构建成功后才可称为正式发布。

## 更新内容

- **全局配置迁移更灵活**：支持密码加密导出和预览导入、合并到当前配置，并对集合、请求、代理、脚本、插件及多类规则等冲突逐项选择保留本机或使用导入值。导入后仍会关闭主动网络与执行权限，并要求重启。
- **实时与历史正文查看**：历史 gRPC 响应按版本分段读取；实时 SSE 可在 gzip、deflate、Brotli、Zstd 及多层压缩下增量查看。普通响应的完整编辑和处理增加明确的大小预算，防止仅为预览解码过大的正文。
- **导出和下载减少内存副本**：桌面会话 JSON/HAR 逐条写入；浏览器有文件选择 API 时背压写入，没有时由本地服务暂存并使用单次下载票据。原始正文下载也采用分段读取。请求文件上传和 Multipart 构造改为分块编码。
- **抓包与协议改进**：新增固定目标 QUIC 反向代理的设置入口；优化原生 H1/H2 SSE 及交互式 gRPC 的实时记录、取消保存和 SQLite 增量快照；WebSocket、脚本与拦截的正文大小检查更早执行。
- **httpcloak 发送改进**：仓内固定的上游 fork 提供流式响应读取，按显式 H1/H2 选择协议；代理隧道中的 H2 响应在 EOF 前可返回，helper 输入按发送进度解码，减少大正文的中间缓冲。
- **桌面关闭保护**：系统菜单退出接入请求草稿和集合保存保护，保存失败时保留当前窗口及内容。

## 使用与兼容边界

配置迁移的加密密码至少 12 个字符；密码不写入配置或恢复点，丢失后无法解密。合并导入不迁移本机证书私钥、代理密码、MCP Token 或抓包历史；导入后请检查并手动启用需要的代理、规则和脚本。详细行为见[配置迁移说明](config-migration.md)。

上述正文优化减少特定路径的完整二进制副本与重复写入，**尚未实现全链路文件引用或有界内存**。Flow、部分 IPC、脚本输入和最终 Base64 仍可能随正文大小增长；大文件并发峰值与目标设备实际下载、关闭、安装和更新仍待实机验收。QUIC 反向代理仅针对固定目标，不等于通用 TUN H3 解密。范围见[路线图](roadmap.md)、[正文内存边界](body-memory.md)和[协议说明](protocols.md)。
