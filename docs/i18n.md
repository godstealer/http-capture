# 界面国际化

顶部工具栏及代理设置中的“语言 / Language”提供跟随系统、简体中文和 English。默认跟随运行环境的首选语言（桌面 WebView 的系统语言，浏览器的首选语言）；zh 系列显示简体中文，其他语言显示英文。监听 languagechange 事件；手动选择优先于系统，并保存到 localStorage 的 http-capture.language。其他同源窗口通过 storage 事件同步。无法访问存储时仍可在当前会话切换。

切换立即生效，不刷新页面、不重新创建工作区，不修改请求、响应、脚本或网络配置。页面 lang 属性和总览时间格式随语言更新。脚本编辑器通过 Compartment 更新辅助属性，保留编辑内容和撤销历史。

实现位于 apps/frontend/src/i18n.ts，英文词典为 apps/frontend/src/locales/en.json。中文原文作为键，新增界面文案使用 t；动态值通过命名占位符传入，禁止对整个请求、响应正文或用户脚本做翻译。模块级文案列表保留原文，在显示时调用 t，避免切换后标签不更新。

覆盖抓包、请求编辑、右键菜单、响应查看、TLS、Header Order、拦截、监听、上游代理、TUN 以及脚本界面和说明。用户脚本示例中的原始代码、已保存的流量注释和内核/外部库返回的诊断信息保留原文；这些诊断尚未采用跨前后端的错误码翻译协议。

验证：npm run build；node scripts/test-i18n.cjs。后者检查字典覆盖、系统回退、手动覆盖、保存与恢复、语言变化事件、插值、中英文组件渲染以及请求数据不被翻译。未进行桌面/浏览器 GUI 点击验收。
