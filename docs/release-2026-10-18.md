## 更新内容

### 请求编辑与保存

- 请求页上方右侧提供「导出代码」「保存请求」，URL 行保留协议、方法、地址、TLS 和发送操作。
- 新请求点击保存后可直接确认预填名称与集合；没有集合时自动创建「我的请求」，无需跳页后再次保存。已保存请求再次保存直接更新；支持另存为、Ctrl/Cmd+S 和 Ctrl/Cmd+Shift+S。
- 请求标签显示已保存名称，集合可再次打开；工作区保存关联在重启后恢复。草稿自动保存和收藏保存分别提示，避免误认。保存失败保留编辑内容，版本冲突不自动覆盖其他窗口。
- 集合同时保存 gRPC 方法、未完成的 JSON 消息与 HTTP/gRPC/WebSocket 模式；兼容旧工作区和集合文件。
- 请求头查看页支持全部/单行复制；请求头编辑继续保留禁用项、重复项和顺序。
- 请求正文提供文本/JSON、URL 编码表单、Multipart 字段/文件、原始二进制文件和 Base64；保留原始字节及不完整编辑内容。

### 导出请求代码

- 按语言和库自动生成当前 HTTP 请求的地址、方法、启用请求头及原始正文，支持复制和下载对应扩展名文件；展示依赖安装提示。
- 共 20 种组合：Python Requests/http.client，JavaScript Fetch/Axios/jQuery/XMLHttpRequest，Node.js Fetch/Axios/Native，Go net/http，C libcurl，C# HttpClient/RestSharp，Java HttpClient/OkHttp，Kotlin OkHttp，Dart Dio，PHP cURL/Guzzle，以及 Shell cURL。
- 导出前应用当前环境及请求变量，不执行请求脚本。二进制、Unicode、JSON 和表单正文均保留原始字节，不重新编码为另一种正文。
- 禁用请求头不进入代码；连接和长度等字段交给目标库生成。字典型库的重复字段合并、浏览器 CORS/受限请求头、GET/HEAD 正文限制均有说明，不承诺 SDK 复刻原始字段线序、TLS 指纹或代理配置。

### 编辑器、主题与设置

- 拦截请求、响应及直接替换正文统一使用 CodeMirror 6；增加可选粘贴后自动格式化，保留手动格式化、撤销和失败时原文。
- 工作区统一左侧功能导航、工具栏、详情、二级页面、输入框及焦点样式；导出/存储管理收进菜单。
- 共十套可保存主题：浅色琥珀、深色薄荷、赛博机甲、极地蓝、暮光紫、暖纸、深海声呐、熔核机库、矩阵终端、樱雪未来。
- 代理设置改成常规、上游代理、系统与证书、HTTPS 解密、TUN 五个选项卡，切换保留输入及滚动位置，支持键盘导航。
- 监听 IP/端口保存并恢复；数字、范围和占用校验仍以实际绑定为最终依据。
- 桌面使用原生 WebView 缩放；浏览器预览统一缩放坐标，修正右键菜单、分栏和文本选择偏移。

### 流量来源与正文暂存

- 请求列表、详情和搜索增加入口、客户端地址与可识别的本机来源进程；Windows IPv4/IPv6 TCP 识别已通过独立进程测试。
- H1、H2 和 WebSocket 连接关联来源，重放不继承捕获来源；导入的来源标记为文件记录，无法识别时明确显示未知。
- 原生 H2/H3 接收和捕获回传按块暂存、回传，正文超过 64 KiB 溢写匿名临时文件；保留流控、取消和错误边界。此项尚未完成全链路低内存改造。

### 正式发布与应用更新

- 构建版本使用正式 GitHub Release，完整产物发布后才设置为 Latest。
- 保留已有安装包使用的 `updater-preview` 清单地址作为兼容更新入口；通道记录本身不作为 Latest，旧构建和重复执行不能回退版本。
- 四平台安装产物、五个签名更新目标、SHA256 和签名清单继续由 CI 汇总。签名私钥和密码不进入源码及附件。

## 验证与待验收

自动化检查与手工实机验收分开记录。发布前执行前端回归/生产构建、内核回归、服务和桌面编译，以及更新清单、签名和发布时序测试；各平台以本提交 CI 结果为准。

用户手工验收按要求暂缓，项目和操作步骤见 [本轮验收清单](acceptance-2026-10-18.md)。浏览器测试使用隔离示例数据，不写入真实抓包集合；生成代码的语义测试替换网络入口，不向网站发送测试请求。

## 已知边界

- TUN 原始进程元数据、macOS 来源识别、Linux 实机验证和 UDP/QUIC 进程识别仍待处理。
- 大正文的公开 DTO、工作区、脚本/断点和前端仍存在完整 Base64 副本；未完成整进程峰值内存测量。
- gRPC 集合保存不替代 Protobuf 定义管理；已建立连接需重新发起。代码导出当前面向 HTTP，不生成 gRPC 或 WebSocket 会话代码。
- 不保证 ANA、StarFlyer、Cebu 等真实业务的 TLS 指纹或反自动化兼容；协议协商通过不等于购票搜索验收通过。
- Windows/macOS/Linux 安装升级、CA 信任、系统代理、原生缩放及目标库实机运行仍需用户验收。其他后续开发见 [路线图](roadmap.md)。
