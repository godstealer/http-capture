# HTTP Capture 正式版更新（2026-10-20，使用反馈与 MCP 增强）

本次修复用户 TODO 中的来源识别、ALPN 协商、响应替换入口、小屏上游按钮及便携版更新提示，并交付 MCP 工具契约、只读资源、操作审计、请求故障模拟和正文范围读取改进。版本号由成功的源 Check 编号确定，安装包和更新清单使用同一来源提交。

## 更新内容

- **来源识别更稳定**：浏览器同时建立多条连接时，进程查询超过并发名额后限时等待，不再直接丢弃识别机会。超时和取消不会无限增加后台线程；仍按真实本机连接识别，不根据网站、端口或旧 PID 猜测来源。
- **HTTPS 协议协商修复**：httpcloak 默认浏览器预设兼容服务端选择 HTTP/2、HTTP/1.1 或无 ALPN。切换 H1 发生在发送 HTTP 数据前，使用同一条已验证的 TLS 连接和原有 HTTP CONNECT/SOCKS5 隧道；读取或网络错误不会触发跨协议重发。显式 H2 和导入 ClientHello 的严格约束保留。
- **H1 请求与响应一致性**：按原位置合并 Cookie，校验唯一且准确的 Content-Length，避免大小写导致重复长度头。ALPN 转交 H1 后保留压缩字节及对应编码和长度头，保证展示与保存的正文含义一致。
- **响应替换更易找到**：抓包详情新增“拦截替换响应”按钮，原右键入口继续保留；编辑完成后使用“替换响应并放行”。操作为后续匹配请求建立断点，不重发或改写已完成的历史请求。小屏详情操作栏支持换行。
- **小屏与便携版体验**：窄屏保留上游代理图标、状态提示和点击入口。Linux 解包便携版明确显示手动更新，增加最新版下载与失败后复制地址；不再把该情况误写为更新源未配置。默认浏览器启动等待有界，不因浏览器持续运行阻塞界面。
- **MCP 工具与资源**：最多 26 个工具补充输出 schema、结构化结果和效果注解；新增操作指南、当前工具契约及受权限限制的规则、脚本资源。HTTP/stdio 均支持资源列表和读取，默认仍只有四个只读工具；注解不替代权限确认，不提供资源订阅。
- **MCP 操作审计**：在“MCP → 操作审计”分页查看认证后的 12 类写工具尝试，最多保留 10,000 条。记录固定元数据和结果，不保存调用参数、正文、URL、凭据或源码；开始记录失败不执行操作，完成记录失败保留真实结果并提示未确认。审计不等同于所有 UI 操作日志，不进入全局配置导出。
- **请求故障模拟**：在“阻止请求 → 故障模拟”按 URL、主机或方法配置请求延迟和固定窗口请求次数限制。超额返回本地 429 / Retry-After；第一条匹配规则生效，支持取消、版本冲突保护和重启保存。全局配置迁移增加模拟规则，导入后保持禁用。
- **正文读取改进**：MCP 每次最多读取 64 KiB 原始正文，持久正文按所需范围读取，支持字节偏移与后续分段；spool 范围检查不截短后续保存或转发。该阶段不是整个应用恒定内存或全链路大文件改造完成。

## 验证与边界

本地完整内核、传输、MCP 和控制服务回归、真实 stdio 子进程、Go helper、前端交互回归、TypeScript、国际化、生产构建及发布验签 fixtures 已通过。ANA 提供的公开 JavaScript 链接只读 GET 实测返回 200 / HTTP/2 / TLS 1.3；没有重放旧业务 POST，此结果不代表 ANA 订票搜索或鉴权通过。

本机 Windows 拒绝启动桌面测试程序，未将这次编译成功记为原生测试通过。正式发布仍必须通过三系统源检查、四组安装包构建，以及四平台构建流程中强制执行的桌面更新生命周期测试；任一门禁失败不会上传正式版。

实际 Linux 用户权限、各发行版桌面环境、安装与真实跨版本更新仍按[验收记录](acceptance-2026-10-20.md)保留。普通连接查询失败仍可能显示未知；macOS 原生来源、TUN 原始进程和 UDP/QUIC 来源尚未完成。eCapture、WinDivert 和 macOS Network Extension 尚未接入，不能据此宣称已支持免代理抓包。

## 使用说明

- Windows 首次安装选择带 `windows-x64` 前缀的 `setup.exe`；Linux 按发行版和运行方式选择 deb、AppImage 或免 FUSE portable；Mac 按 Intel / Apple Silicon 选择对应 DMG。
- 已安装版本通过“检查更新”下载安装；Linux 解包 portable 使用提示中的下载链接。更新仍要求签名与 TLS 验证。
- 操作说明：[MCP](mcp.md)、[故障模拟](request-faults.md)、[配置迁移](config-migration.md)、[流量来源](traffic-origin.md)、[TODO 修复记录](todo-feedback-2026-10-20.md)。更早版本与未完成事项见[路线图](roadmap.md)。
