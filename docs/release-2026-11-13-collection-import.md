# HTTP Capture 桌面版更新说明（2026-11-13）

本版包含 0.1.75 之后的桌面改动。正式版本号由同一源码提交的 GitHub Check 编号确定；跨平台检查、打包及更新附件验证通过后发布。

## 更新内容

- “集合与环境”新增外部集合导入入口，支持 Postman Collection v2.0/v2.1、Hoppscotch Collection、OpenAPI 3.0/3.1、Insomnia Export v4、HAR 1.2 的 JSON 文件，以及单条 cURL 命令。ApiFox、ApiPost、Paw 等可先从原工具导出 Postman v2.1 或 OpenAPI 3 JSON。
- 导入前显示集合、请求及环境数量和转换提示。外部请求追加到当前集合，不覆盖已有数据；点击“保存集合与环境”后才写入磁盘。原文件在本机解析，不上传。新增名称、正文和集合容量校验，避免生成无法保存的集合。
- 导入保留可映射的请求方法、URL、有序请求头、禁用状态、文本正文和部分常见认证；文件正文、无法转换的认证或脚本会显示提示，不能安全还原的请求会跳过。HAR 只导入请求快照。
- “导入 cURL”弹窗加宽至桌面可用宽度，并增大命令输入区，方便检查长请求头和正文。

## 验证边界

定向格式导入测试、完整前端回归及生产构建通过。Insomnia v5 YAML、OpenAPI YAML、Swagger 2.0 和其他工具的专有导出格式暂不支持。浏览器净化后的 HAR 可能缺少 Cookie 或 Authorization，导入后请核对再发送。本版仅发布桌面安装包；Android/iOS 真机验收与正式移动安装包仍在[开发清单](roadmap.md)中。macOS M1 安装启动及真实跨版本自动更新仍需设备验收。
