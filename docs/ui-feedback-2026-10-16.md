# 编辑器与使用反馈修复（2026-10-16）

状态：0.1.16 发布后的开发增量，尚未发布。本文记录本轮编辑器需求和使用中发现的五项问题，不改变 [0.1.16 更新说明](release-2026-10-16.md) 的已发布范围。其他开发待办继续见 [路线图](roadmap.md)。

## 本轮修改

1. **拦截正文编辑器**：请求、响应和直接替换响应均使用 CodeMirror 6，支持语法高亮、行号、折叠、撤销和 `Shift+Alt+F`。UTF-8 模式可按 Content-Type 自动识别或选择 Text、JSON、HTML/SVG、JavaScript、CSS；保留静态预览、Base64 和文件替换入口。
2. **粘贴后自动格式化开关**：请求正文和拦截正文共用选择，默认关闭并保存。开启后，仅在文本粘贴结束时格式化支持的语言；粘贴与格式化是两个独立撤销步骤。Worker 异步执行，超过 1 MiB、语法错误、超时均保留原文并提示。继续编辑、切换正文/语言/编码/预览、关闭开关、恢复和关闭编辑器会使旧结果失效。Text、Base64、文件和表单不执行代码格式化。
3. **请求头复制异常**：抓包详情的头部页增加“复制全部头部”和每行复制按钮，字段值可直接鼠标选中。原始头部、Base64 页也有复制按钮，缺失原始数据时禁用复制。普通字段保留顺序、重复项、大小写与空值；原始头部使用单字节映射保留已记录的报文字节，未凭空生成 HTTP/2 原始头部。
4. **请求正文类型**：明确提供文本/JSON、URL 编码表单、Multipart 表单/文件、原始文件/二进制、Base64 高级模式。按 Content-Type 载入捕获的表单，包括同名字段和文件。仅切换类型不会清空或转换现有正文；类型不匹配或无法无损解码时保留原正文，需显式新建表单后应用。原始文件直接使用字节，不经过文本解码；二进制内容不会把占位提示写回正文。生成新正文会更新 Content-Type 并移除启用的旧压缩/长度头；高级 Base64 编辑保留内容编码含义，禁用头部保留。
5. **界面缩放定位**：桌面改用 Tauri 原生 WebView 缩放，避免根节点 CSS zoom 的光标命中偏移。浏览器开发预览改为 body 缩放，并统一换算右键菜单、列表列宽和分隔条坐标；菜单会收敛到窗口边界，缩放时关闭旧菜单。
6. **面板布局**：整理正文类型/语言工具栏、文件和表单卡片、字节数/MIME 提示、拦截编辑区和放行操作；完善输入边界、明暗主题的代码颜色、焦点与错误状态。
7. **监听端口保存**：保存有效监听 IP 和端口并在下次启动恢复。输入仅接受数字、最多五位，范围 1024–65535；失焦与“完成”共用占用检查，检查失败时不关闭弹窗，未完成/非法输入不覆盖已保存值。启动时仍以实际 bind 结果为准。关闭弹窗取消该实例未完成的检查；存储失败会提示本次会话有效。浏览器开发页与桌面版各自保存设置，不自动启动监听。

## 验证

- Node.js 24 执行前端完整回归，覆盖正文格式化取消/并发、粘贴与格式化分步 Undo/Redo、拦截上下文切换、文件取消、监听恢复/占用/失焦与完成、缩放换算、头部复制及既有工作区功能。开发环境要求 Node.js 22+；旧 Node 18 的 FormData 解析会重排文件字段，不能用于保序回归。
- 前端 TypeScript 与 Vite 生产构建通过。新增 Worker 作为独立构建产物，不在主线程执行正文格式化。
- Windows 桌面 `cargo check --locked -p http-capture-desktop` 通过，包含原生 WebView 缩放权限声明校验。
- 本地浏览器实际操作验证：JSON 粘贴/关闭开关/失败保留/分步撤销、HTML/JavaScript/CSS 格式化、开关刷新恢复、格式化保留已编辑的 URL 和头部、URL 编码重复字段及中文特殊字符、二进制原始文件、Multipart 文件应用和重新载入、Base64 不格式化。
- 浏览器六档缩放（75/90/100/110/125/150%）实际鼠标验证：普通输入框与 CodeMirror 光标和文字拖选、右键菜单锚点和边界、列表列宽与分隔条拖动。头部全部/单行/原始数据复制已读取剪贴板核对，包括重复字段和空值。编辑面板的明暗主题均已查看。

桌面原生缩放、重启和多平台实机验收仍按此前要求暂缓；浏览器和自动化结果不算桌面实机验收完成。拦截文件替换维持 8 MiB 上限，压缩正文需先替换为解压后的正文再编辑。全链路低内存、协议和系统集成待办没有因此清零。

## 追加：整体工作区视觉统一

按“整体不够美观”的反馈重新整理布局，而非仅调整正文面板。抓包、拦截、阻止、集合、插件统一放入左侧功能导航；顶部只保留当前工作区、代理状态、上游摘要和主要操作。语言与缩放归入分组设置，TUN、证书、上游及系统代理入口保留在设置中。请求标签有独立滚动区，保存成功状态移到底栏，保存失败仍明确显示。

统一浅色/深色的工作台背景、内容面、边框、文字、强调色与焦点变量。列表使用轻底色选中态、方法颜色和状态标记；保留真实 32px 行高、36px 表头和原有虚拟滚动。正文、请求头、详情、集合/环境、插件、阻止与拦截页同步调整；设置弹窗分组、内容独立滚动，标题、关闭与完成按钮固定。

原先常驻的导出、保存、数据库维护改为“导出与保存”“存储管理”菜单，原功能保留；支持点击外部、Escape 收起和键盘互斥。请求右键菜单也使用统一主题，继续按实际窗口位置收敛。修正组合 URL/搜索输入框的重复边框。

本地隔离示例数据已检查：中英文、浅深主题、1440/1280/1024/853px 的列表/详情与重放编辑布局，集合/环境、插件、阻止和拦截空状态及规则网格；管理菜单的键盘互斥、Escape、右键菜单样式；1280×800 浏览器预览在 150% 下，捕获按钮、底栏及设置弹窗均完整位于窗口内。测试页拦截所有控制请求，不连接或写入用户真实抓包数据库。前端完整回归及生产构建通过；尚未发布，桌面实机验收继续暂缓。

## 追加：赛博 · 机甲主题

右上角主题菜单新增第三个选项「赛博 · 机甲」（英文 Cyber · Mecha），保持原有浅色/深色和默认选择。主题采用黑蓝面板、青色选中态、少量橙色机甲边角、硬边输入框与等宽控制台字体；侧栏、工具栏、请求列表、正文编辑器、规则页、菜单、设置和更新提示共用配套颜色。网格和装饰放在面板边缘，不叠加闪烁或扫描线。

主题选择本地保存，刷新恢复；存储不可用时仍可在当前会话切换。暗色基础样式按 color-scheme 共享，赛博样式全部限定在独立主题内，切回浅色/深色不会残留。新增回归覆盖三主题、刷新恢复、无效值和存储读写异常；虚拟列表维持 32px 行高与 36px 表头。尚未发布，桌面实机验收继续暂缓。

## 追加：设置选项卡与更多皮肤

代理设置拆为「常规」「上游代理」「系统与证书」「HTTPS 解密」「TUN」。常规包含外观和监听设置；其余功能及各自保存/执行按钮完整保留，底部说明上游与解密策略需在各页保存。窗口尺寸固定，标题、选项卡和完成按钮不随正文滚动；每页记住滚动位置。隐藏页保持挂载，切换不会重置代理名称/认证、解密域名或 TUN 应用草稿，也不会触发保存或启动操作。

支持左右方向键首尾循环、Home/End、选中页单一 Tab 焦点；首次打开聚焦目标选项卡。顶部上游摘要和请求设置中的「管理代理」直接打开上游页，普通设置入口打开常规。完成仍等待监听校验；失败时核对原组件身份后切回常规并聚焦错误输入，防止旧检查干扰重新打开的弹窗。端口错误颜色跟随主题，避免暗色下硬编码红色不清楚。

新增三套主题：极地蓝（冰白/蓝色/银边）、暮光紫（深紫/薰衣草/柔和玫瑰）、暖纸（米白/墨棕/细纸纹与衬线标题，编辑内容维持等宽）。连同浅色琥珀、深色薄荷、赛博机甲，共六套，可在右上角选择并保存。新皮肤规则限定各自主题，编辑器语法、WS、更新提示和原生下拉选项均配套，不改变虚拟列表行高和缩放坐标。

验证：隔离真实 App 的浏览器示例已检查五页切换、代理/域名/TUN 草稿保留、滚动恢复、键盘导航、两个上游快捷入口，以及从其他页完成时端口占用错误自动定位；三套新皮肤已实际查看，1280×720 中英文与 100%/150% 布局正常，刷新恢复、控制台检查通过。六主题全部 36 种状态切换、各主题刷新恢复、存储异常及前端完整回归通过，TypeScript/Vite 生产构建通过。示例没有连接或写入真实抓包服务；尚未发布，桌面实机验收继续暂缓。

## 追加：直接保存与代码导出（2026-10-18 发布批次）

请求区上方右侧放置“导出代码”和“保存请求”，不再占用 URL/发送行。新请求预填名称与默认集合，无集合时创建“我的请求”，一次确认即可落盘；后续保存更新关联记录，另存为生成副本，支持 Ctrl/Cmd+S、Ctrl/Cmd+Shift+S。标签显示保存名称，可从集合再次打开；工作区重启保留关联，旧数据兼容。gRPC 模式、方法和未完成 JSON 消息随集合保存。草稿自动保存独立提示，保存失败保留输入，整库 CAS 冲突不会自动覆盖。

代码导出提供语言和库两个选择框，共 20 组合；展开所选环境和请求变量，不执行脚本，只包含启用字段与原始正文。所有目标使用规范化的 Base64，保留二进制与 Unicode 字节，目标需要时按块拼接长字符串。SDK 自动字段、重复字段合并、浏览器 CORS、方法正文限制和 TLS/代理边界明确提示。支持剪贴板复制和对应扩展名下载，桌面保存通过原生选址窗口。

隔离浏览器实际确认：新建默认保存、快捷键更新不重复、关闭后从集合恢复、另存为失败保留输入并可重试、gRPC 方法及未完成 JSON 恢复、上方按钮布局、语言/库切换和代码复制。浏览器下载验证卡在系统保存窗口，未计入已通过；原生窗口、150% 新弹窗、SDK 实机发送与跨平台安装升级等留在 [验收清单](acceptance-2026-10-18.md)。测试未写入真实抓包集合，也未运行生成代码向站点发请求。

前端完整回归和生产构建、内核全量回归、服务/桌面编译、18 项正式发布与签名时序回归通过。代码导出包含 20 目标校验、7 个 Web/Node 目标 28 份语法及 21 次隔离语义测试；Python 语法、Go gofmt、Java 编译及离线内容检查通过。未安装的 C#/Dart/Kotlin/PHP 工具链和第三方 SDK 实机编译不冒记为通过。发布详情见 [版本说明](release-2026-10-18.md)。
