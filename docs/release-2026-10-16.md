# HTTP Capture 预览版更新说明（2026-10-16）

本版为 `build-7d3c9919ad91`（2026-10-14 发布）之后的增量。安装包版本由本次成功的 Check 编号生成，格式为 `0.1.N`；实际版本、提交与下载文件见对应 GitHub Release。先完成同一提交的 Check，再构建四个平台，全部签名产物验证通过后发布。

## 更新内容

- **新增请求阻止（Block）**：支持 URL 包含、正则、精确域名与可选方法条件，可分别启停规则，配置自动保存。抓包列表右键可按 URL 或域名添加规则；被阻止的请求显示 BLOCK、匹配原因和本地 403，不发送到源站。可选择仅作用于抓包或同时作用于手动请求。
- **请求头编辑更方便**：每一行和全部请求头均可启用/禁用，禁用项保留但不发送；新增文本编辑框，可粘贴浏览器复制的请求头批量导入，并复制已启用的请求头。保留字段顺序、重复字段及草稿中的禁用状态，继续支持上下移动和删除。
- **修复 TLS / HTTP2 转发协商**：HTTPS MITM 在与客户端握手前协商上游 TLS，并根据实际上游 ALPN 选择下游协议、复用已建立连接。HTTP2 转 HTTP1 时正确合并重复 Cookie；HTTP2 转 HTTP2 保留重复 Cookie 和收到的字段顺序。分别展示客户端与上游协议。
- **改善预览与编辑界面**：图片和 SVG 支持适应窗口、缩放与双向滚动；HTML/SVG 使用静态隔离预览。请求正文补齐 JSON、HTML、JavaScript、CSS 格式化；统一输入框边框、背景和焦点样式，当前使用的上游代理增加高亮标记。
- **完善监听和响应拦截入口**：端口仅接受数字，校验 1024–65535 及监听地址上的端口占用；请求右键新增响应拦截替换入口，可快速建立对应规则，再在拦截面板修改并放行响应。
- **新增签名应用内更新**：桌面版启动及运行期间检查新版本，支持查看更新说明、稍后提醒、跳过版本、手动检查、下载进度、失败重试、安装后重启。安装前保存请求草稿、恢复系统代理并停止监听；下载和安装分别校验更新签名。发布流水线生成 Windows、Linux 与两种 macOS 架构的签名更新包。

## 使用与升级

- 旧版 `0.1.0` 尚无更新入口，需要先手动安装本版；之后使用工具栏“检查更新”或自动更新提示。
- Windows x64 使用 NSIS `.exe`；Linux x64 可选择 `.deb`、`.AppImage` 或免 FUSE 的 `portable.tar.gz`；macOS Intel 与 Apple Silicon 使用各自的 `.dmg`。
- 应用内更新使用 Windows NSIS、Linux 对应的 AppImage/Deb，以及 macOS 对应的应用归档。解包后的 Linux portable/AppDir 继续手动更新。
- 本版使用独立预览频道 `updater-preview`，不改变 GitHub 的 stable latest。更新清单指向固定 `build-<sha12>` 资产；旧构建晚完成不会回退更新版本。
- 安装包继续包含原生引擎和 httpcloak 辅助程序；不包含可选 wreq 与 TUN helper。更新签名用于验证更新包，Windows 代码签名和 macOS 签名/公证仍待配置。

## 尚需处理

1. **发布后的真实更新验收**：用本版安装包验证首次安装，再发布更高版本测试完整下载、安装、重启和数据保留；分别验证 Windows、Linux AppImage/Deb 与两种 macOS 架构。首次签名流水线通过不等于这项已完成。
2. **桌面与系统集成**：原生关闭/系统菜单退出保存、安装/卸载、系统代理恢复及凭据库实机验收；Windows 代码签名、macOS 签名/公证、macOS 系统代理与 macOS/Linux CA 自动管理。
3. **大文件低内存链路**：正文文件引用贯穿收发、存储、浏览器引擎 IPC 和前端；脚本/断点按需读取及并发峰值内存压测。已解除普通请求的固定大小拒绝和增加暂存，不代表全链路已完成；拦截面板的文件替换入口仍限制 8 MiB。
4. **协议与保序边界**：HTTP2 SETTINGS/优先级、完整 ClientHello 编辑、响应头及帧级保真、Reqable HTTP2 MITM 独立对照；H3/浏览器引擎 SSE、压缩流增量解析、WebSocket 流式脚本/断点、扩展 CONNECT。普通字段保序不代表 TLS 指纹、HPACK 或 HTTP2 帧字节一致，也不保证航空网站完整搜索流程通过。
5. **后续功能**：gRPC 实时代理双向流、多 schema、插件扩展界面/菜单/流式钩子、按规则选择上游与嵌套规则。TUN H3 实机排查继续暂停。

阻止规则不能检查未解密 CONNECT 内的 URL/方法；不带方法的精确域名规则可以在连接源站前阻止 CONNECT。启用规则不切断已经建立的 WebSocket 或其他流式会话。对照请求头时，HTTP2 的 `:authority` 与普通 Host 应分别理解，未强制插入 Host 或改写成固定“浏览器顺序”。
