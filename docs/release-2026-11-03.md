# HTTP Capture 桌面版更新说明（2026-11-03）

本版包含 0.1.70 之后的桌面改动。正式版本号取同一源码提交的 GitHub Check 编号，只有跨平台检查、打包和附件核验完成后才发布。

## 更新内容

- 请求、响应及拦截正文现在支持 XML 格式化和语法高亮；识别 `application/xml`、`text/xml` 及 `+xml` 类型。手动请求编辑 XML 时保留原有 MIME 类型。
- macOS 安装包增加临时应用签名，并在打包后验证签名，处理 Apple Silicon 下载包被判为“已损坏”的已知问题。

## 使用与验证边界

临时签名不是 Apple Developer ID 签名或公证。macOS 仍可能要求在“隐私与安全性”中允许打开；M1 真实设备安装仍需验收。Android 局域网协同抓包尚待设备端到端验证，本版不发布正式移动安装包。其余待办见[开发清单](roadmap.md)。
