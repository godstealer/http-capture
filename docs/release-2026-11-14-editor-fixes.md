# HTTP Capture 桌面版更新说明（2026-11-14）

本版包含 0.1.77 之后的桌面修复。正式版本号沿用同一源码的 GitHub Check 编号，完整四平台构建和签名校验通过后公开。

## 更新内容

- 修复 Linux 便携版跳过更新查询的问题。更新界面显示当前版本与最新版本，发现较新版本时才提供下载入口；同版、旧版和查询失败时不显示下载按钮。便携版继续采用手动下载安装。
- 请求标签增加右键菜单：关闭当前、其他、左侧、右侧或全部请求标签。固定“调试”页保留，批量关闭会取消对应发送任务并清理 WebSocket。
- cURL 导入支持重复的内联 `--data-urlencode` 字段，保留字段顺序及空值，按 UTF-8 编码并正确处理空格和特殊字符；支持配合 `-G/--get` 将数据追加到 URL 查询。文件和标准输入形式仍需改为内联内容。
- 修复响应文本 Ctrl+F / macOS ⌘F 的键盘焦点及请求、响应面板归属。打开搜索后直接聚焦查询框，Enter 可跳转到下一匹配；分页文本、Hex 和 Base64 支持搜索当前页。
- 请求体字段区改为紧凑键值表格，使用统一列标题、小图标删除和底部“＋ 添加字段”操作；修改状态与应用按钮放在独立页脚，适配浅色、深色及窄面板。新增字段后会定位并聚焦字段名。
- 空请求体默认显示“无正文”，URL 查询参数与请求体分开展示。表单直接提供输入行，未编辑的占位行不会生成多余字段；切换正文类型可暂存待应用字段，实际发送内容在点击“应用到请求体”后更新。主动选择“无正文”会清空已有正文。

## 验证边界

完整前端回归、类型检查及生产构建已通过；已用真实 CodeMirror 状态与 DOM 模拟交互验证搜索和新增字段，用五组本机 cURL 回环请求对照方法、URL、正文字节及 Content-Type。原生更新器及同源跨平台检查以本次发布记录中的实际结果为准。

Linux 便携版更新查询、目标桌面 WebView 的视觉与键盘操作、M1 实机安装和真实跨版本更新仍待设备验收。分页搜索仅覆盖当前已读取片段，不自动读取完整大正文。本版仅发布桌面安装包，Android/iOS 设备验收与正式移动安装包继续保留在[开发清单](roadmap.md)中。
