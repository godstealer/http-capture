## 更新内容

- **自动替换整份响应**：新增“响应重写”页面，按 URL、精确域名及可选方法匹配，统一替换状态码、有序响应头和完整正文。支持 UTF-8、Base64、本地文件及“保存并启用此规则”，自动处理后续匹配响应。
- **文本与正则局部修改**：保持状态码，按顺序查找替换 UTF-8 正文，或设置、查找替换、删除响应头。支持分组、大小写和首次/全部匹配；保留重复字段及顺序，常见压缩正文受限解压，实际改变后更新长度并清理失效编码和校验头。
- **规则顺序与手动断点分开**：上游仍正常访问，全部匹配规则在响应后脚本/插件之后按列表执行；单条失败只回滚该条，原始响应继续保留。侧栏、详情及右键区分自动重写与手动响应断点，模板默认禁用，支持排序、复制、搜索及版本冲突保护。
- **编辑一致性与规则迁移**：更改正文或文件时移除旧 Content-Digest、Repr-Digest 等失效摘要，原样重复输入保留原头；共享头部编辑器区分请求/响应语境。配置迁移新增响应重写类别，只有显式包含内容才导出规则，导出和导入均关闭总开关与各条规则。
- **历史列表只读元数据**：现代内核的历史及增量轮询不携带请求、响应、原始请求和原始响应四槽正文，仍保留全部历史、顺序、删除及重开/reset。只有旧内核明确缺少端点才兼容完整历史，其他错误不触发全量回退；同时移除无人消费的桌面完整 Flow 事件转发。
- **选中正文按版本分页**：四个 HTTP 实体按所选记录和版本每页最多读取 64 KiB，支持页码跳转、文本/Hex/Base64 和当前片段复制。空实体与未加载正文分开表示；有限片段不作为完整文本解压、格式化或预览，记录更新或删除时拒绝混读。
- **有预算的完整实体预览**：不超过 64 KiB 的完整实体继续默认格式化和预览；64 KiB–8 MiB 需明确点击完整处理，仅拼接所选实体，不顺带读入其他三槽。自动替换模板同样只读取完整响应实体；更大正文保留分页和完整下载，普通抓包不受该处理预算限制。
- **完整操作保持完整内容**：完整 cURL/JSON 复制、编辑、重放及会话 JSON/HAR 导出使用固定版本的完整记录，失败不复制前缀、不创建缺正文草稿或保存不完整文件。支持文件选择 API 时先选位置再读取；会话导出仍聚合完整记录，未宣称流式低内存导出。
- **完整原始实体独立下载**：桌面按版本分块写入并原子发布，HTTP 先准备私有临时文件释放数据库锁，再分块传输；支持浏览器文件选择 API 时按背压写入，无该 API 时明确使用完整 Blob 缓冲。保留原内容编码，当前下载上限为 256 MiB。
- **隐藏面板停止正文处理**：切换记录、实体、版本、页码，隐藏或断线后释放片段和显式完整缓存，拒绝旧异步结果；隐藏响应不挂解析 Worker。gRPC 会话保持运行，隐藏时停止记录正文读取/解码，小记录有 64 KiB 四槽总预算，大记录需显式完整加载。

## 从哪里使用

- 自动规则：侧栏 **响应重写**，或抓包详情/右键 **自动替换响应 / 自动修改响应**。填写匹配及内容后点击 **保存并启用此规则**；“保存全部规则”尊重当前开关，不自动启用。
- 片段查看：选中抓包记录，打开请求或响应的 **正文 / Base64** 页；可以上一片段、下一片段或输入页码跳转。片段复制与完整数据操作分别标识。
- 完整格式化与预览：较大实体在正文页点击 **加载完整正文用于格式化或预览**；只在不超过 8 MiB 时提供此处理。
- 保存实体：点击 **下载完整原始实体**，保存完整原始字节。完整会话 JSON/HAR 继续使用保存菜单；取消或版本冲突不会改用当前片段。

详细操作见[自动响应重写](response-rewrite.md)、[正文内存改造](body-memory.md)与[配置迁移](config-migration.md)。

## 范围和内存边界

自动响应重写仍最多 32 条规则、每条最多 32 项修改，配置最多 16 MiB；整份替换与文本修改的输入、受限解压和结果最多 8 MiB。文本须为有效 UTF-8 且无 NUL；显式非 UTF-8 字符集和二进制类型不做局部正文修改。HEAD、204、205、206、304 不做局部正文修改；整份替换遵守 HEAD/204/205/304 无正文约束。WebSocket、SSE、gRPC 流式响应跳过自动重写，上游失败不伪造成功或重发原请求。

历史与预览的改动只覆盖四槽 HTTP 实体正文。WS 帧、原始头、SSE/gRPC 累计、网络最终 Base64、脚本/helper、内部模型、编辑器、完整会话聚合导出及无文件选择 API 的 Blob 路径仍可能持有完整数据。gRPC 大记录显式加载仍还原完整 Flow，解压后消息预算和长会话累计内存待处理。**P0 全链路低内存没有完成**，真实大文件、慢速、并发和取消峰值尚待测量；不以只读片段代替完整保存或转发。
