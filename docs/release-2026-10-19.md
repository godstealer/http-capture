# HTTP Capture 正式版更新（2026-10-19，MCP 与配置迁移）

本轮在 0.1.23 的基础上补齐 MCP 新手接入、AI 请求工作流、断点与脚本管理，以及全局配置导出、导入。版本号由成功的源 Check 编号生成，全部平台构建与签名汇总成功后发布正式版。当前发布状态以[最新正式版本](https://github.com/godstealer/http-capture/releases/latest)及本轮 CI 为准。

## 更新内容

- **MCP 接入向导与离线说明**：页面可直接阅读完整新手文档，生成 Codex、Cursor、VS Code 和通用客户端配置。支持 Streamable HTTP 与应用自身的 stdio 桥接，无需额外安装 Node.js；显示最近活动的 AI 客户端名称、协议和时间。
- **AI 管理请求与集合**：按独立权限读取、创建和修改请求草稿，创建集合并保存请求；界面自动同步已保存修改。版本冲突保留本地输入，避免覆盖其他窗口的工作。
- **AI 断点与响应替换**：单独授权后可配置断点、查看等待项及正文、放行、终止或替换响应，复用已有拦截管线和头部校验。
- **AI 全局抓包脚本**：单独授权后可读取脚本 API、生成模板、校验并保存代码；保存后保持禁用，启用需确认当前版本。脚本读取权限包含代码与变量，界面明确说明。
- **全局配置迁移**：代理设置新增“配置迁移”选项卡，导出标准 JSON，在新设备先预览再替换所选类别；支持集合环境、规则、偏好、代理定义、可选草稿及脚本插件代码。默认清空请求内容与变量值，敏感业务内容可显式选择；不导出证书私钥、本机 Token 或代理密码。
- **导入恢复与重启保护**：导入前保留本机恢复点，SQLite 配置一次提交并检查预览版本；导入后停止网络功能、冻结配置编辑并要求重启，导入的脚本、插件及 MCP 保持关闭。代理定义从旧 JSON 兼容迁移到 SQLite，不按源设备 ID 关联本机密码。
- **连接与更新退出保护**：stdio 仅连接正在运行的同一内核；应用停服后桥接退出，Windows 更新会等待已验证的桥接进程释放可执行文件。Linux AppImage 配置使用持久的安装文件路径。
- **Cookie 拆分与合并**：在 Cookie 字段名旁直接拆分当前字段，或按原列表顺序合并相同启用状态的 Cookie；保持其他字段位置、重复键和禁用状态，不操作 Set-Cookie。请求编辑和拦截共用入口；原生 H2 与 httpcloak H2 按编辑字段发送，httpcloak 不再自动重拆且保留 TLS 预设；H1 按协议使用分号合并。

## 已知边界

配置迁移首版是未加密 JSON，按类别替换，尚不支持自动合并或加密迁移；文件上限 16 MiB，导入需要重启。设备的证书信任、代理密码、应用路径和外部 MCP 授权需要在新设备重新配置。MCP 面向本机，不提供远程 OAuth、内置模型或自动上传抓包；持续在线状态不由最近活动列表推断。安装版 AI 客户端、真实升级、跨设备迁移和各平台系统集成仍待手工验收。
