## 更新内容

- **MCP 双向接入**：左侧新增 MCP 页面。AI 客户端可通过本机 Streamable HTTP 查询记录、分块读取正文，并按单独授权发送/取消请求及启停同一个抓包监听器。默认关闭，独立 Token，默认隐藏敏感头和敏感 URL 参数。外部服务页支持 HTTP/stdio 连接、工具目录、JSON 参数和手动调用；HTTP Token 仅保留本次会话。
- **插件在线编辑**：保留本地 JSON 导入，新增 manifest、beforeRequest/afterResponse 的 CodeMirror 编辑器；可检查语法后保存，不执行用户代码。新建和修改后默认禁用，显式启用才进入请求管线。补齐使用文档、界面帮助和三个可预览示例。
- **插件管理整理**：紧凑列表支持名称搜索、启用状态与执行范围筛选；只展开当前插件详情，操作失败保留编辑内容，插件数量增多时不再堆满大段代码。
- **集合新增入口**：保存按钮旁新增菜单，分别创建集合、环境、保存当前请求和脚本模板。名称使用独立弹窗，保存请求的集合选择旁提供新建按钮，首次保留默认集合流程。
- **草稿冲突恢复**：多个窗口编辑导致保存版本冲突时可显式合并重载；保留远端草稿，同一标签双方均修改时另建本地副本，避免强制覆盖。
- **httpcloak 重放修复**：捕获记录带有普通 HTTP/2 伪头时可正常发送。实际伪头根据当前方法、URL 和所选浏览器预设重新生成；保留原捕获信息，并在发送说明中注明预设顺序。
- **减少大正文副本**：HTTP Flow/快照/广播/拦截使用共享正文引用；SQLite 和脚本/helper 序列化减少中间 Base64 副本，保持旧 JSON 与数据库兼容。完整文件引用和峰值内存测量仍待后续完成。
- **全局配置迁移设计**：补充导出/导入范围、敏感信息处理、预览与冲突恢复方案，作为后续实现依据；本版尚未提供全局配置导出/导入按钮。

## 已知边界

MCP 首期面向本机，不提供远程 OAuth，也不内置 LLM 或自动上传抓包。插件 API v1 的菜单/扩展面板和流式钩子仍待实现。全局配置迁移仅设计，不属于已实现功能。完整大文件低内存、TUN H3 实机、macOS 来源识别、真实安装更新及目标网站业务验收继续按[路线图](roadmap.md)推进。
